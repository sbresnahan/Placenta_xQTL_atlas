Placenta xQTL Atlas

A cross-ancestry atlas of molecular quantitative trait loci in the human placenta — from association mapping to fine-mapped causal variants.

This site accompanies the Placenta_xQTL_atlas repository. The two analysis reports and their two companion literature reviews are rendered as native chapters of this site — use the sidebar to navigate between sections, or start from any document below.

The documents

Report 1 · xQTL mapping

Association mapping across nine RNA modalities and two ancestry strata (EAS, EUR): cohort QC, pipeline calibration, the discovery catalog, cross-ancestry sharing, and functional enrichment.

Report 2 · Fine-mapping

Cross-ancestry SuSHiE fine-mapping: credible sets, posterior inclusion probabilities, cross-ancestry effect concordance, functional-annotation enrichment, and gene-set enrichment of high-confidence genes.

How to read this atlas

Start with Report 1 for the association-mapping landscape, then Report 2 for the fine-mapped causal-variant resolution. The two literature reviews are narrative companions that interpret the headline loci against prior work; each cites an indexed evidence table (xqtl_top_hits_evidence_table.csv, finemap_hits_evidence_table.csv in the repository reports/ folder).

Source and data

The bookdown source for this site lives in the repository bookdown/ folder; analysis sources, helper modules, and companion tables live in reports/. Self-contained standalone HTML versions of the four documents are distributed separately with the reports archive. Input data are regenerated on the computing cluster with reports/make_report_archive.sh.
