17 Gene-set enrichment of high-confidence fine-mapped genes

Per-modality over-representation analysis of genes whose best credible set resolves to a high-confidence causal variant (lead PIP >= 0.9), against GO (BP/MF/CC), KEGG, MSigDB Hallmark, and the curated pregnancy/placenta collection. Primary background: all fine-mapped genes of the same modality (tests what distinguishes confidently resolved loci among significant ones); sensitivity background: the HPLRv2 reference universe. BH FDR within each modality x database x background. Computed by run_finemap_enrichment.R; results read from cache.
